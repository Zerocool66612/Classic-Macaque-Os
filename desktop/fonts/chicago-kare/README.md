Source: https://github.com/KingDuane/Chicago-Kare

The publisher describes this as a recreation of Susan Kare's classic Chicago
bitmap typeface. It is used here as an optional retro interface font, with
DejaVu Sans fallback. This is not an Apple-supplied font file.
The font is also staged into /usr/share/fonts/truetype/macaque for installed apps.
